# AnimatedThumbnails-Scratch
Change your Scratch project thumbnail to an animated GIF in one click.

## Setup

1. Download this repo.
2. Open `chrome://extensions/` in your chrome.
3. Enable **Developer mode** (top right).
4. Click **Load unpacked** and select the extension folder.
5. Done :D

## Usage

1. Go to any your Scratch project page(not editor).
2. Click the extension icon.
3. Select a GIF.
4. Done. Your project thumbnail is now animated. :D
